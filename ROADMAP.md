# My Path into Cybersecurity

Start date: 2026-08-16
Goal: learn the fundamentals (networking, Linux, Python, core security concepts) before choosing a specialization (offensive / defensive / AppSec / forensics).

---

## Track 1: Git & GitHub (do this in the first week)

- [x] Create a GitHub account
- [x] Install Git locally, configure `git config user.name` / `user.email`
- [x] Complete "Learn Git Branching" (learngitbranching.js.org)
- [x] Create a repository `cybersecurity-journey`
- [x] Set up structure: `notes/`, `writeups/`, `scripts/`, `README.md`
- [x] Make the first commit

---

## Track 2: Networking (~3-4 weeks)

- [ ] What is an IP address, port, protocol
- [ ] TCP/IP model (simplified)
- [ ] How DNS works
- [ ] How HTTP / HTTPS works
- [ ] Basics: routers, switches, firewalls — understand "why they're needed"
- [ ] Practice: NetworkChuck (YouTube) — basic networking playlist
- [ ] Practice: Cisco NetAcad — intro modules (free)

Notes for this block → `notes/networking.md`

---

## Track 3: Linux (~3-4 weeks, can run in parallel with networking)

- [ ] Install VirtualBox + Ubuntu or Kali Linux
- [ ] Linux filesystem, terminal navigation
- [ ] Permissions (chmod, chown, sudo)
- [ ] Processes, services (ps, top, systemctl)
- [ ] Package management (apt)
- [ ] Practice: OverTheWire — Bandit (all levels, or as many as you get through)

Notes for this block → `notes/linux.md`

---

## Track 4: Python (ongoing, throughout the whole period)

- [ ] Syntax: variables, loops, conditionals, functions
- [ ] Working with files
- [ ] Strings and regular expressions (basics)
- [ ] `requests` module — simple HTTP requests
- [ ] `socket` module — basic network interaction
- [ ] Write your first script (e.g. a simple port scanner or file parser)

Scripts → `scripts/`

---

## Track 5: Security fundamentals + practice (core track — TryHackMe)

- [ ] Complete the TryHackMe "Pre Security" learning path in full
- [ ] Understand the CIA triad (confidentiality / integrity / availability)
- [ ] Understand the terms: vulnerability vs exploit vs attack vs threat
- [ ] Solve the first 3-5 rooms on TryHackMe, write them up

Write-ups → `writeups/`

---

## Checkpoint: choosing a specialization

After finishing tracks 2-5, pick a direction:
- [ ] Offensive (penetration testing, red team)
- [ ] Defensive (SOC, blue team, monitoring)
- [ ] AppSec (application security, code review, web)
- [ ] Digital forensics / incident response
- [ ] Cloud security
